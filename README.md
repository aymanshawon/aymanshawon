## 📡 Private Network Monitoring Bot

I developed a private **Telegram-based network monitoring and troubleshooting automation system** for internal use.

The system helps investigate network issues by analyzing traffic and performing automated network tests.


```text
                    TRAFFIC FLOW
                         │
                         ▼
                ┌─────────────────┐
                │ Network Analysis│
                └────────┬────────┘
                         │
              ┌──────────┴──────────┐
              ▼                     ▼
       ┌─────────────┐       ┌─────────────┐
       │ IP Latency  │       │ Traceroute  │
       │    Check    │       │   Analysis  │
       └──────┬──────┘       └──────┬──────┘
              │                     │
              └──────────┬──────────┘
                         ▼
                ┌─────────────────┐
                │ Issue Detection │
                └────────┬────────┘
                         │
                         ▼
                ┌─────────────────┐
                │ Telegram Report │
                └─────────────────┘
```

## ✨ What It Does

- 📊 Follows traffic flow
- 🌐 Checks IP latency
- 📍 Performs traceroute
- 🔎 Helps identify connectivity problems
- 🚨 Detects potential network issues
- 📢 Automatically reports issues to a Telegram channel

> 🔒 **Private Project:** Source code and internal implementation are not publicly available.
